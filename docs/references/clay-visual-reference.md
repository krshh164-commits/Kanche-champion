# Kanche visual reference: Clay-inspired mobile UI

Source reference: `C:\Users\anasw\Downloads\DESIGN-clay (1).md`.

This project keeps the source as visual guidance, not as product requirements. The user's Kanche brief remains authoritative.

## Applied direction

- Warm cream page canvas: `#FFFAF0`.
- Deep teal gameplay surface: `#1A3A3A`.
- Mint/teal objective card and target marbles.
- Ochre/amber shooter: `#E8B94A`.
- Rounded floating cards using 16–24px radii.
- Hairline borders, restrained soft shadows, and generous whitespace.
- Inter/system sans-serif typography with compact uppercase HUD labels.
- Touch targets of at least 44×44px.

## Deliberately not copied

- Clay marketing navigation, illustration assets, mascots, product cards, footer, and multicolor content rhythm.
- Crowded grids or decorative UI unrelated to gameplay.
- Licensed Plain Black typography; the game uses the supplied Inter/system fallback.

## Kanche-specific composition

The portrait game opens directly into one round. A three-card HUD sits above a centered rounded playfield. Six large teal marbles use a compact 3–2–1 formation, with an amber shooter near the bottom. The scoring rectangle remains visual and nonphysical.
